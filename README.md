# Console de Demonstração DevOps V3

Página interativa para apresentação dos três desafios de Terraform + Docker Desktop + LocalStack.

## Como abrir
1. Descompacte a pasta.
2. Abra a pasta no VS Code.
3. Abra `index.html`.
4. Use **Open with Live Server** ou abra `index.html` diretamente no navegador.

## Antes da apresentação
- Abra o Docker Desktop.
- Inicie o LocalStack.
- Confirme com `docker ps`.
- Mantenha o LocalStack na porta 4566.
- Clique em **Iniciar demonstração**.

## Observação
A animação representa visualmente o fluxo arquitetural. Ela não consulta Docker ou LocalStack em tempo real.
Os botões das aplicações acessam endpoints locais reais e funcionarão quando o LocalStack estiver ativo.
